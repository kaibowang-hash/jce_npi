# UI reference images

These images are Simplified Chinese visual baselines for geometry, density, hierarchy, layout, state treatment, and the single-primary-color rule. They are not production screenshots and are not translation catalogs.

M1 must generate and review equivalent English, Simplified Chinese, and Traditional Chinese fixtures/screenshots from the same English source strings and Frappe-compatible translation source. Language-specific screenshots may not be produced by manually editing labels in the image.
