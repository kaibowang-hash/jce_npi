# UI/交互评审 Prompt

使用 `industrial-ux`、`frappe-i18n` 和 `npi-domain-guard` skills，评审 `[页面/流程]`。不要只评价美观，不要自行实现。

先核对唯一视觉基线：Siemens Industrial Experience / 经典西门子工程软件。逐项检查：
- 是否采用固定应用栏、矩形左导航、紧凑工具条、对象头、表格/树/分栏和停靠式检查器；
- 用户是否围绕项目/模具/试模对象工作，而不是围绕单据类型跳转；
- 主任务、主动作、对象状态、来源、同步状态、可编辑端是否一眼可见；
- 中性色是否占 85%–90%，是否只有一个主色；语义色是否仅小面积使用；
- 普通组件是否保持 0–2px 圆角，页面面板是否无阴影；
- 是否出现彩色 KPI 卡片墙、渐变、玻璃效果、强阴影、装饰插画或消费级风格；
- 是否能从“我的工作”或项目驾驶舱在两次上下文切换内完成；
- 加载、空、错误、无权限、只读、冲突、异步处理中、部分成功是否完整；
- 高风险动作是否显示影响摘要、锁定版本、权限、原因和确认；
- 表格是否支持保存视图、筛选、受控批量操作、键盘和大数据性能；
- 是否用颜色之外的文本/图标表达状态；
- 1366×768、1920×1080、125% 和 150% 缩放是否可用；
- 英文源字符串是否通过翻译适配器；英文、简体中文、繁体中文页面是否存在普通语言混用；
- Tooling、NPI 和质量术语是否与白名单和词表一致；
- 是否有不必要弹窗、深层菜单、重复字段或被迫离开上下文；
- 是否复制 Siemens 品牌资产，而不是使用公司自有主题。

输出：`PASS` 或 `BLOCKED`、严重问题、可用性风险、视觉偏差、语言偏差、需求 ID 偏差、建议修复和可验证验收。
