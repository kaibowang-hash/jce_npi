# 仅规划 Prompt

请阅读 `AGENTS.md`、已批准 ADR、当前里程碑和任务上下文。当前只允许规划，不允许编辑任何代码、配置、数据库或依赖。

对任务 `[TASK_ID]` 输出：
1. 你确认的目标与用户价值；
2. 范围与明确非范围；
3. 依据的需求 ID、ADR、契约和现有代码证据；
4. B/C 类歧义及待决定选项；
5. 拟修改/新增文件；
6. 数据模型、权限、API、UI 状态、审计和 ERPNext 影响；
7. 测试矩阵；
8. 迁移、回滚和开关策略；
9. 最小提交顺序；
10. 完成定义映射。

不要实现，也不要把未确认项偷偷转成实现假设。


UI 与语言硬约束：任何终端页面必须遵守 Siemens 式单主色、方正、扁平、高密度基线；所有用户文案以英文为源并通过 Frappe 翻译目录输出，中文/英文均不得出现普通语言混用。涉及 UI 使用 `industrial-ux`，涉及文案使用 `frappe-i18n`。
