# 单任务执行 Prompt

执行任务：`[TASK_ID]`。只执行这一项；不要开始下一项。

开始前：
- 阅读根 `AGENTS.md`、当前任务、相关 docs/contracts、已批准 ADR 和相关 skill。
- 输出 10 行以内的实施确认：范围、非范围、关键假设、文件、测试、风险、迁移/回滚。
- 遇到 B/C 类歧义立即停止相关部分并说明，不得自作主张。

实施要求：
- 做最小完整纵切，不做附近的 nice-to-have。
- UI 不得退化为原始 DocType CRUD 页；使用统一 App Shell、领域语言和定义好的交互状态。
- 权限和校验必须后端落实。
- ERPNext 写操作必须走执行请求和可靠集成，不得跨库。
- 不得假成功、静默失败、硬编码 ID、空实现或 TODO 占位。
- 新依赖须先有获批 ADR。
- 按任务验收增加测试和可复现证据。

结束时只输出：
1. 已完成的验收项；
2. 变更文件；
3. 测试命令及真实结果；
4. UI/API/迁移证据；
5. 未完成或风险；
6. 回滚方式；
7. 唯一建议的下一任务（不得执行）。


UI 与语言硬约束：任何终端页面必须遵守 Siemens 式单主色、方正、扁平、高密度基线；所有用户文案以英文为源并通过 Frappe 翻译目录输出，中文/英文均不得出现普通语言混用。涉及 UI 使用 `industrial-ux`，涉及文案使用 `frappe-i18n`。
