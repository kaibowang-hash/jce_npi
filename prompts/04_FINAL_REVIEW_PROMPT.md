# 合并前最终评审 Prompt

对 `[TASK_ID/PR]` 执行 release-gate。先阅读任务验收、相关 ADR、契约、代码和测试结果。

必须验证：
- 没有越界功能、核心补丁、跨库访问、双主编辑和未批准依赖；
- 权限、审计、版本锁、错误/重试和同步状态均真实；
- 所有声明的测试已实际运行，不接受“应该通过”；
- migration 可重复、向后兼容或有明确停机/回滚；
- OpenAPI、事件 schema、data ownership 与代码一致；
- UI 的所有状态和键盘/可访问性基础可验证；
- 无硬编码密钥、测试后门、静默 catch、假数据、TODO 占位；
- 文档和实际行为一致。

输出 PASS / BLOCKED。BLOCKED 时列出精确证据和最小修复清单；不得为了通过而降低门禁。


UI 与语言硬约束：任何终端页面必须遵守 Siemens 式单主色、方正、扁平、高密度基线；所有用户文案以英文为源并通过 Frappe 翻译目录输出，英文、简体中文、繁体中文均不得出现普通语言混用。涉及 UI 使用 `industrial-ux`，涉及文案使用 `frappe-i18n`。
