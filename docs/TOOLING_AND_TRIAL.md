# Tooling 与试模领域规格

## 1. Tooling 项目类型

### A. 客户来模
重点是所有权、保管责任、接收差异、维修授权和量产验证。
流程：
1. 登记客户模具资料、运输、配件和责任界面；
2. 到厂照片和检查：外观、尺寸、穴位、热流道、水路、电气、安全、备件；
3. 差异/风险清单与客户确认；
4. 维修/改造授权及 ERPNext 采购/费用关联；
5. 试模、样件、质量批准；
6. ERPNext 模具资产/位置/维护映射；
7. 返还/移动/封存证据。

### B. 按图新制模具
重点是 DFM、设计、制造供应链、预算、试模迭代和验收。
流程：
1. 产品输入和 DFM；
2. Tooling 规格与方案；
3. 报价/预算、make-or-buy、供应商和 ERPNext PO 执行；
4. 模具设计修订、评审、释放；
5. 制造里程碑：备料、热处理、粗/精加工、电极、装配、试模准备；
6. T0–Tn；
7. 缺陷闭环、样件批准、验收；
8. ERPNext 资产创建/更新和正式移交。

### C. 改模/变更
引用正式变更，冻结旧/新输入，管理改模范围、责任、报价、停机、试模和生效。

## 2. 模具开发驾驶舱信息

### 对象头
- Tooling code / name；
- 项目、客户、产品；
- 类型、所有权、保管方；
- 穴数/穴位映射；
- 当前生命周期状态；
- 当前设计修订；
- 供应商；
- 目标/预测/实际日期；
- 预算、承诺、实际和预测成本；
- 当前试模轮次与结论；
- ERPNext Asset/Mold ID、状态、位置、同步状态。

### 生命周期
`需求/接收 → 设计 → 制造 → T0–Tn → 验收 → ERP 资产 → 量产观察`

每个节点显示计划/实际、负责人、阻断和证据。用户点击节点在当前页面下钻，不打开一串新标签。

### 标签
- 概览
- 规格
- 设计与版本
- 制造与供应商
- 试模
- 缺陷/行动
- 成本与 ERP
- 验收/资产
- 文件/活动

## 3. Tooling 规格

基础字段：
- 类型：两板/三板/热流道/包胶/嵌件/家族模等；
- 模架/模芯材料、硬度、表面处理；
- 穴数、穴位标识、产品映射、备穴；
- 热流道品牌/区域/接口；
- 水路、电气、油压/气压、抽芯；
- 外形、重量、吊装、安全；
- 适用机台吨位/拉杆间距/射胶量；
- 目标周期、寿命、保修；
- 客户标准、接口、备件、交付文件。

字段可按模板扩展，但核心语义与单位统一。修改已批准规格需要修订和影响分析。

## 4. 设计管理

- 设计输入引用产品/客户图纸具体修订和 DFM 结论；
- Design Revision 包含 2D/3D、BOM、评审清单、问题、批准和文件哈希；
- 状态按领域模型执行；
- 制造只能引用 released 修订；
- 释放后变化通过新修订或批准偏差；
- 可比较元数据和文件清单；CAD 几何差异作为后续集成，不伪装已具备；
- 评审问题可直接创建行动并定位文件/截图/区域描述。

## 5. 制造与供应商

- Milestone 模板按自制/外发/混合配置；
- 每个里程碑含计划/实际、责任人、供应商、证据、风险和依赖；
- 供应商更新需要授权、审计和项目范围隔离；
- 采购、收货、发票和实际成本从 ERPNext 只读投影；
- NPI One 不修改正式 PO 行；需要变化时发起 ERP 执行/变更请求；
- 逾期或成本偏差触发项目健康度和恢复计划。

## 6. 试模轮次

### 6.1 创建
从 Tooling 创建 Trial Round：
- 自动建议 T0/T1… 序号，允许受控调整；
- 可从前一轮克隆参数和未关闭缺陷；
- 选择目的：首次试模、改模验证、设计验证、材料/颜色验证、能力试验、客户送样等；
- 指定计划日期、机台、人员、材料、样件和测量计划。

### 6.2 输入版本锁
准备完成前必须选择并锁定：
- 产品设计修订/基线；
- Tooling 设计修订；
- 模具实体/穴位配置；
- 材料、色号、添加剂和批次；
- 参数表模板版本；
- 检验计划/图纸版本；
- 关联变更或偏差。

如输入在试模前变更，系统显示差异并要求重新确认；不能悄悄指向最新版本。

### 6.3 实际记录
- 机台、辅机、环境、模温和材料状态；
- 注塑参数分阶段记录，支持单位和目标窗口；
- 周期、稳定时间、投入/良品/不良；
- 样件批次、穴号、编号、照片和去向；
- 异常停机、临时调整和操作者；
- ERPNext Quality Inspection/NCR 链接。

### 6.4 缺陷
缺陷包含：
- 类型、位置/穴号、严重度；
- 发现轮次、图片/标注；
- 产品/模具/工艺/材料/测量初步归因；
- 根因、遏制、永久措施；
- 责任、目标轮次、验证证据；
- 状态和阻断规则。
缺陷可跨轮次延续，但每轮验证结果独立。

### 6.5 结论
`pass / conditional_pass / tooling_change / design_change / process_tuning / material_change / cancelled`
结论前展示：
- 必填数据和证据；
- 重大缺陷；
- 与上轮变化；
- 质量结果；
- 需要创建的下一任务/下一轮；
- 对 Gate/NPI 的影响。
提交后冻结快照。改动需重开并审计或创建新轮次。

## 7. 轮次比较

至少支持：
- 输入版本差异；
- 参数差异和窗口；
- 周期/良率；
- 穴号尺寸/缺陷；
- 新增/关闭/复发缺陷；
- 样件与质量结论；
- 改模/改图/调机措施；
- 一页式总结导出。

## 8. 模具验收

验收分为：
- 技术规格；
- 设计/制造文件；
- 试模与质量；
- 周期/产能；
- 备件和维护；
- 安全/接口；
- 保修/责任；
- 成本/PO/发票状态；
- 资产和位置数据。

批准后创建 `ExecutionRequest: create_or_update_tool_asset`。工程验收不等于 ERP 资产已建立；两种状态必须分别显示。
